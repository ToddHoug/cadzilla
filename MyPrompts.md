Setup this session to create 8080 assembly language programs to be compiled and run under CP/M 2.2 and running them on the altairsim emulator.
Use altairsim emulator installed at ~/altairsim , referencing the examples/ai_mcp/ example and the 
docs/DRIVING_WITH_AI.md document. Follow the process of creating the 8080 assembly code, transferring it to altairsim, driving the CP/M assembler and examining the output.

Each new program should reside in it's own directory in the software/ directory.
Create a new 8080 assembly program called "hello" that will output a welcome/hello string to the CP/M console.
